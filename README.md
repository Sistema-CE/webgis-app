# WEBGIS GEO — versão modular inicial

Estrutura:

- `index.html`: estrutura da interface e carregamento das bibliotecas.
- `css/style.css`: estilos visuais da aplicação.
- `js/app.js`: lógica atual preservada integralmente.

Esta primeira modularização não altera funcionalidades. Depois da validação online, o arquivo `app.js` poderá ser separado em módulos menores.
